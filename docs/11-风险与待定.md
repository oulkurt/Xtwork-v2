# 11 风险与待定

## 需要实跑的关键问题

| 问题 | 影响 | 何时验证 |
|---|---|---|
| Dim alpha 的 ACP 模型目录、权限流和守护进程行为 | 默认助手、隐藏运行时名称、退出 | M0 跑通单模型、MCP、退出；按 [03](03-内置运行时-Dim.md) 和 [13](13-模型网关.md) 记录 |
| 生产 WebView 的本机受信源、预加载和桥接 | 窗口显示、文件选择、通知 | M0 验证原始界面，M1 用正式构建再验证 |
| Windows 启动参数传递、WebView2 和 Node 原生依赖 | Windows 安装版 | M0 独立探针，M3/M5 在干净系统中验收 |
| 多会话使用免项目目录 | 写同名文件冲突 | M1 同时开两个会话，必要时分配独立目录 |
| 模型通过可见工具正确记事 | 聊天与插件绑定是首发核心 | M2 用固定用例验证工具暴露，M3 验证直接记录、澄清和撤销 |
| 模型端点收到笔记内容 | 数据出站符合用户选择 | M2 从实际请求核对发送与移除的区别 |
| 第三方插件执行边界 | 本机数据与工具权限 | M2 验证宿主能力、进程和 iframe 边界；公开分发前另行评估 |
| IM 平台权限、凭据和重连 | 候选平台上线范围 | M4 用真实测试租户验收 |
| T3 上游改动返工 | 产品持续维护 | 第一次同步跑一遍补丁、品牌扫描和冒烟 |

## 产品决策清单

| 编号 | 需要决定 | 规划中的建议 | 最晚确认 |
|---|---|---|---|
| Q-01 | 名称、图标、发布源、标识 | 内测可用 xtwork_v2 代号，对外发布前锁定 | M1 产包前 |
| Q-02 | 开发者功能清单 | PR 和 Issues 只留在设置，先精简终端、工作树等入口 | M1 界面冻结前 |
| Q-03 | 首发模型由产品提供还是用户自带 Key | 用本地通道验证技术，面向普通用户优先产品提供模型 | M1 用户体验验收前 |
| Q-04 | 首个 IM 平台与能力 | 飞书私聊试点，先验证收消息和返回任务结果 | M4 开工前 |
| Q-05 | 本地数据是否提供导入 | v2 使用新目录。首发需求明确后再做显式导入 | M5 范围冻结前 |
| Q-06 | 相对时间及模糊意图是否直接录入 | 明确意图直接记并可撤销，模糊时问一句 | M3 交互冻结前 |
| Q-07 | 是否默认后台运行、何时补提醒 | 仅启用需要后台的功能时建议开启，并在托盘明确提示 | M3 |
| Q-08 | Obsidian 是否首发写入 | 首发验收读取和引用，写入需显式确认 | M3 |
| Q-09 | IM 是否支持在聊天中审批 | 随首个平台能力一起验证，风险高的动作可以回桌面 | M4 |
| Q-10 | 插件分发和插件工坊 | 放在三项内置插件稳定之后 | 首发后 |
| Q-11 | T3 上游同步节奏 | 【已定】等官方稳定版发布后评估，见 [同步流程](02-上游与改造层.md#5-同步流程) | 已确认 |
| Q-12 | 首发平台 | macOS arm64 预览；Windows x64 独立验收；其余待定 | M5 产包前 |

平台次序、默认权限和可见入口以原型反馈和实测为准。已经定下的技术方向见 [规划首页](../README.md)。

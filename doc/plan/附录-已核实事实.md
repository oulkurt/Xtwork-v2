## 2. mygo

`WindowOptions.URL` 可加载本机服务页面，`PageOptions.TrustedOrigins` 和 `PreloadScript` 提供桥接接入点。单实例、通知、对话框、自启和凭据已有原生接口。生产构建的 origin、注入时机和跨平台行为在 M0 验证。 [WebView](https://github.com/egoist/mygo/blob/v0.10.0/docs/ui/web-view.md) · [原生功能](https://github.com/egoist/mygo/blob/v0.10.0/docs/native.md)

## 3. T3 Code

- `apps/server` 有单独的 CLI。上游打包把 Web 产物放在 `dist/client`。桌面 WSL 路径已有 `--bootstrap-fd 0`。 [打包脚本](https://github.com/pingdotgg/t3code/blob/3ce2145864f1e8b822cc8dff9c8cfdf39d9e450b/apps/server/scripts/cli.ts#L92-L98) · [stdin 启动](https://github.com/pingdotgg/t3code/blob/3ce2145864f1e8b822cc8dff9c8cfdf39d9e450b/apps/desktop/src/backend/DesktopBackendConfiguration.ts#L741-L754)
- PR 和 Issues 入口由侧栏环境能力守卫。品牌还出现在本机应用标识、应用支持目录、遥测端点、由上游运营的登录和远程连接。参照第 09 章确定替换项。 [侧栏](https://github.com/pingdotgg/t3code/blob/3ce2145864f1e8b822cc8dff9c8cfdf39d9e450b/apps/web/src/components/sidebar/SidebarChrome.tsx#L279-L311) · [遥测](https://github.com/pingdotgg/t3code/blob/3ce2145864f1e8b822cc8dff9c8cfdf39d9e450b/apps/server/src/telemetry/AnalyticsService.ts)
- ACP provider 支持本地命令和参数。上游上下文信封可投递已引用的自定义类型。 [ACP 设置](https://github.com/pingdotgg/t3code/blob/3ce2145864f1e8b822cc8dff9c8cfdf39d9e450b/packages/provider-acp-registry/src/settings.ts#L7-L48) · [上下文投影](https://github.com/pingdotgg/t3code/blob/3ce2145864f1e8b822cc8dff9c8cfdf39d9e450b/packages/shared/src/composerContextReferences.ts#L394)

## 4. Dim

开源 Rust 发布带 ACP 和本地 App Server。固定发布版已有 `prompts.base` 和 HTTP MCP。该版 `--model-config` 与 ACP 可切换的产品模型目录走不同路径。 [提示词配置](https://github.com/arcships/dim/blob/v0.1.0-alpha.25/docs/design/appserver/prompt-overrides.md) · [ACP 网关](https://github.com/arcships/dim/blob/v0.1.0-alpha.25/crates/dim-acp/src/gateway.rs) · [ACP 模型配置](https://github.com/arcships/dim/blob/v0.1.0-alpha.25/crates/dim-acp/src/config.rs)

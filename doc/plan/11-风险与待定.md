| 共享 OS SecretStore 删除回读验证与并发栅栏 | 防止钥匙串删除失败仍宣称退出或在途刷新回写旧凭据 | M1b-Gate 1 已合入 `main`（PR #24 `im-bridge/src/platform/secrets.ts` + `runtime/secretStore.ts`），真机钥匙串回归随 M1b-Gate 2 复核 |
| Keycloak 回调端口 `49160` 与旧 Electron 版同时登录冲突 | 并装阶段企业微信登录体验 | M1b-Gate 2 验证端口占用中文提示与快速释放 |

| Pi 经 T3 MCP `delegate_task` 委派至 Claude / Codex / ACP Agent 的执行与上下文合同 | 非 Git `scratch/` 首条消息委派、结构化简报、父级递归取消、普通模式登录终端与 IM 硬拒绝 | M1c-Gate 2 端到端实跑，核验子进程凭据隔离与 ADR-011 IM 硬拒绝 |
| 模型通过可见工具正确记事 | 聊天与插件绑定是首发核心 | M2 用固定用例验证工具暴露，M3 验证直接记录、澄清和撤销 |
| 模型端点收到笔记内容 | 数据出站符合用户选择 | M2 从实际请求核对发送与移除的区别 |
| 第三方插件执行边界 | 本机数据与工具权限 | M2 验证宿主能力、进程和 iframe 边界；公开分发前另行评估 |
| IM 平台权限、凭据和重连 | 候选平台上线范围 | M4 用真实测试租户验收 |
